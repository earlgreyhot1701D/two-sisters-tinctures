# Two Sisters Tinctures

A skincare shelf tracker built for my little sister. She adds a product by pasting ingredients, typing a name, or snapping the label. Gemma 4 reads and explains what it does. Deterministic code decides routine order, morning or night, warnings, and expiry. Her shelf lives on her phone only.

Built during the **Hacktoberfest Weekend Challenge: Build for a Friend** (October 2–5, 2026).

## Tech Stack
- **AI Core:** Gemma 4 (`gemma-4-26b-a4b-it`) via Gemini API
- **Frontend:** Vanilla HTML, CSS, JavaScript (zero heavy frameworks)
- **Design:** Apothecary aesthetic inspired by custom typography (IM Fell DW Pica & Libre Caslon Text)
- **Deployment:** Render (`render.yaml` blueprint with Node web service)
- **Pair Programming:** Developed with Google Antigravity IDE & DevRelay

## Local Development
```bash
# Run the local server
npm start
```
Visit `http://localhost:3000` in your browser.
